# LearnJapanese.jp — Japanese Learning Platform

**A Web-Based Japanese Learning Platform | 日本語学習プラットフォーム**

[English](#english) | [日本語](#japanese)


## English

### 1. Project Overview

LearnJapanese.jp is a web-based Japanese learning platform designed to help learners study Japanese through structured lessons, vocabulary, grammar, Kanji, and practical learning resources.

The platform provides learning materials for different Japanese proficiency levels, including JLPT N5 to N1. It also includes specialized learning resources for Japanese communication and caregiving (Kaigo).

This project demonstrates practical web application development, database management, and the implementation of interactive learning features.

### 2. Main Features

- **JLPT Kanji Learning:** Structured Kanji learning resources covering N5 to N1.
- **Japanese Grammar:** Grammar lessons and learning materials.
- **Vocabulary Learning:** Vocabulary resources organized by JLPT levels.
- **Example Sentences:** Japanese example sentences to support practical understanding.
- **Kaigo Learning:** Specialized Japanese caregiving terminology and reading resources.
- **Japanese Driving Resources:** Learning materials related to Japanese driving terminology and licenses.
- **User Learning Resources:** Organized educational content for Japanese language learners.

### 4. Project Highlights

- Structured Japanese learning content across JLPT levels.
- A Kanji database containing over 2,600 Kanji entries.
- More than 10,000 Japanese example sentences.
- Organized learning content with 139 lessons and 525 pages.
- Dedicated Japanese caregiving vocabulary resources containing over 1,500 terms.

*Figures represent the project's recorded content and may change as the platform develops.*

### 6. Local Development Environment

The project was developed and tested in a local macOS environment using MAMP, PHP, and MySQL.

To run the project locally:

1. Install a compatible PHP and MySQL environment.
2. Clone this repository.
3. Configure the local database connection.
4. Set up the required database using your own database backup or schema.
5. Configure required application settings locally.
6. Run the project through a local PHP web server.

**Important:** Do not commit passwords, API keys, private configuration files, or production database credentials.

## 日本語

### 1. プロジェクト概要

LearnJapanese.jp は、日本語学習者を対象としたWebベースの日本語学習プラットフォームです。

JLPT N5からN1までの学習者に向けて、漢字、文法、語彙、例文などの学習コンテンツを提供します。

また、介護分野の専門用語や日本の運転免許に関連する日本語学習資料も用意しています。

本プロジェクトでは、Webアプリケーション開発、データベース管理、学習機能の実装に取り組みました。

### 2. 主な機能

- **漢字学習：** JLPT N5〜N1に対応した漢字学習コンテンツ
- **文法学習：** 日本語文法のレッスンと学習教材
- **語彙学習：** JLPTレベル別の語彙学習
- **例文：** 日本語の理解を深めるための例文
- **介護日本語：** 介護分野の専門用語と読み方の学習
- **運転関連の日本語：** 日本の運転免許に関する学習資料
- **学習コンテンツ管理：** 日本語学習者向けの教材を体系的に管理

### 3. 使用技術

| 技術 | 用途 |
|---|---|

| MySQL | データベース管理 |
| JavaScript | インタラクティブ機能 |

| CSS3 | デザインとレイアウト |
| Composer | PHPライブラリの管理 |
| Stripe PHP SDK | 決済機能関連 |

### 4. プロジェクトの特徴

- JLPT N5〜N1に対応した日本語学習コンテンツ
- 2,600件以上の漢字データ
- 10,000件以上の日本語例文

- 1,500語以上の介護関連用語
